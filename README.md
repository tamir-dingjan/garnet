# garnet
Geometric alignment for proteins

This tool is an efficient, lightweight geometric alignment utility to align protein structures. The approach is similar to [ProBiS](http://probis.cmm.ki.si/), using a combination of solvent-exposure, chemical descriptors, and graph clique detection to align protein structures.
